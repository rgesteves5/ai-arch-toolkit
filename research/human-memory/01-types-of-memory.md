# Types of Memory

## Overview

Human memory is organized into several distinct systems, categorized by duration, content, and the brain systems that support them. Memory is not a single faculty — it is a collection of interrelated systems that serve different functions.

---

## Memory by Duration

### Sensory Memory

Sensory memory is the shortest-lasting form of memory. It acts as a buffer for incoming sensory information, holding raw, unprocessed sensory data for a very brief period. If the brain deems the input important, it gets passed along to short-term memory. Otherwise, it fades almost instantly.

There are subtypes based on the sense involved:

#### Iconic Memory (Visual)

- Duration: approximately 250–500 milliseconds
- Holds a brief visual snapshot of what you just saw
- Example: If someone waves a sparkler in the dark, you briefly "see" a trail of light — that's your iconic memory holding the image for a split second
- Studied extensively by George Sperling in the 1960s using partial report paradigms

#### Echoic Memory (Auditory)

- Duration: approximately 3–4 seconds
- Holds a brief auditory echo of what you just heard
- This is why you can sometimes "replay" something someone just said even if you weren't fully paying attention
- Longer duration than iconic memory because auditory information unfolds over time and requires a longer buffer to be meaningful

#### Haptic Memory (Touch)

- Duration: approximately 2 seconds
- Holds brief tactile sensations
- Less studied than iconic and echoic memory but follows the same general principles

### Short-Term Memory / Working Memory

Short-term memory can hold a limited amount of information for a brief period without rehearsal.

#### Capacity

- Classic estimate: "7 plus or minus 2" items (George Miller, 1956)
- More recent research suggests the true capacity is closer to 4 items (Nelson Cowan)
- Capacity can be expanded through **chunking** — grouping individual items into meaningful units (e.g., remembering "FBI-CIA-NASA" as three chunks rather than nine letters)

#### Duration

- Information decays within about 20–30 seconds unless actively rehearsed
- **Maintenance rehearsal** (simple repetition) keeps information in short-term memory but doesn't reliably transfer it to long-term memory
- **Elaborative rehearsal** (connecting new information to existing knowledge) is much more effective for long-term retention

#### Baddeley's Working Memory Model

Working memory is a more active, multi-component version of short-term memory, proposed by psychologist Alan Baddeley. It is not merely a passive store but an active workspace for manipulating information.

**The Phonological Loop:**
- Handles verbal and acoustic information
- Consists of a phonological store (holds speech-based information for 1–2 seconds) and an articulatory rehearsal process (refreshes information through subvocal repetition)
- This is what you use when you repeat a phone number in your head
- Explains why it's harder to remember words that sound similar (the phonological similarity effect) and why longer words are harder to remember (the word-length effect)

**The Visuospatial Sketchpad:**
- Handles visual and spatial information
- Used for mental imagery, spatial reasoning, and navigation
- Example: mentally rotating an object, remembering where you parked your car, or visualizing a map
- Has separate visual (what things look like) and spatial (where things are) components

**The Central Executive:**
- Acts as an attention controller and coordinator
- Decides what to focus on, switches attention between tasks, and coordinates the other subsystems
- The most important but least understood component
- Closely linked to prefrontal cortex function
- Impaired in conditions like ADHD and frontal lobe damage

**The Episodic Buffer:**
- Added to the model later (2000) to address gaps
- Integrates information from different sources (phonological loop, visuospatial sketchpad, long-term memory) into coherent episodes
- Acts as a bridge between working memory and long-term memory
- Limited capacity of approximately 4 chunks

### Long-Term Memory

Long-term memory stores information for extended periods — from hours to a lifetime. It has no known capacity limit. Long-term memory is divided into two major branches based on whether the memory is consciously accessible.

---

## Long-Term Memory: Explicit (Declarative)

Explicit memory involves information that can be consciously recalled and "declared" or articulated. It is further divided into two subtypes.

### Episodic Memory

- Stores personal experiences and events — your autobiography
- Includes not just what happened, but the full context: where you were, when it happened, who was there, how you felt, what you perceived
- Memories are often vivid and emotionally colored
- The **hippocampus** plays a critical role in forming and retrieving episodic memories
- Episodic memories are tagged with spatial and temporal context — you remember not just the event but when and where it occurred
- Tends to decline more with aging than other memory types
- Particularly vulnerable to diseases like Alzheimer's, which attacks the hippocampus early
- Studied extensively through patients with hippocampal damage, such as the famous patient H.M. (Henry Molaison), who could not form new episodic memories after bilateral hippocampal removal
- Endel Tulving was a pioneer in distinguishing episodic from semantic memory

### Semantic Memory

- Stores general knowledge and facts detached from personal experience
- Your mental encyclopedia — concepts, categories, word meanings, historical facts, scientific principles
- Example: You know that Paris is the capital of France without remembering when or where you learned it
- More resistant to aging and brain damage than episodic memory
- Supported by the **anterior temporal lobes** and widespread neocortical regions
- Over time, episodic memories can become "semanticized" — you remember the fact but lose the personal context of when and how you learned it
- Patients with semantic dementia progressively lose conceptual knowledge, starting with unusual or less frequently encountered items

---

## Long-Term Memory: Implicit (Non-Declarative)

Implicit memory operates below conscious awareness. You express these memories through performance rather than conscious recollection.

### Procedural Memory

- Stores learned skills, habits, and motor sequences
- Examples: riding a bicycle, typing, playing a musical instrument, tying shoelaces, driving a car
- Slow to form — requires extensive practice and repetition
- Remarkably durable once established — "it's like riding a bike"
- Supported primarily by the **basal ganglia**, **cerebellum**, and **motor cortex**
- Independent of the hippocampus — patients with severe amnesia who cannot form new explicit memories can still learn new motor skills
- This dissociation was demonstrated in H.M., who improved at mirror tracing tasks despite having no conscious memory of having practiced them
- Progresses through stages: cognitive (conscious, effortful, error-prone) → associative (more fluid, fewer errors) → autonomous (automatic, requires minimal attention)

### Classical Conditioning

- Learned automatic associations between stimuli
- Example: feeling anxious when you hear a dentist's drill, salivating when you smell food cooking
- The **amygdala** is heavily involved in fear conditioning specifically
- Ivan Pavlov's foundational experiments with dogs demonstrated how a neutral stimulus (bell) paired with an unconditioned stimulus (food) produces a conditioned response (salivation)
- Conditioning can occur even in patients with no conscious memory of the conditioning sessions — demonstrating its implicit nature

### Priming

- Exposure to one stimulus influences your response to a later stimulus, without any conscious intention or awareness
- Example: If you recently saw the word "doctor," you would recognize the word "nurse" faster than an unrelated word like "table"
- Types of priming:
  - **Repetition priming**: Faster processing of a stimulus you've recently encountered
  - **Semantic priming**: Faster processing of a stimulus related in meaning to something you've recently encountered
  - **Perceptual priming**: Faster processing based on the physical form (visual, auditory) of a stimulus
- Priming effects can last from seconds to months depending on the type
- Can occur even when the person is unaware of the prime — subliminal priming

## Other Important Types of Memory

### Prospective Memory

- Remembering to carry out future intentions — "remembering to remember"
- Two forms:
  - **Time-based**: Remembering to do something at a specific time (e.g., take medication at 8 PM)
  - **Event-based**: Remembering to do something when a specific cue appears (e.g., give a message to a friend when you see them)
- Surprisingly error-prone — this is why people rely on reminders, alarms, to-do lists, and calendars
- Depends on the **prefrontal cortex** for maintaining intentions and monitoring for cues
- Declines with aging, particularly time-based prospective memory
- Different from retrospective memory (remembering past events) — prospective memory involves remembering that something needs to be done in the future

### Emotional Memory

- Involves the **amygdala** working alongside the hippocampus to strengthen memories tied to strong emotions
- Strong emotions (fear, joy, surprise, grief) enhance how vividly and durably an event is stored
- The amygdala modulates memory consolidation in other brain regions — it doesn't store the memory itself but amplifies the storage process
- **Flashbulb memories**: Vivid, detailed, and confident memories of emotionally significant events (e.g., where you were when you heard major news)
  - Despite their vividness and the person's high confidence, research shows flashbulb memories can be surprisingly inaccurate over time
  - The feeling of certainty does not guarantee accuracy
- Emotional memory serves an adaptive function — it's biologically important to remember events that were dangerous, rewarding, or otherwise significant for survival
- Traumatic memories can become overly strong and intrusive, as seen in PTSD, where the amygdala's influence on memory consolidation becomes maladaptive

### Autobiographical Memory

- Overlaps with both episodic and semantic memory
- Refers to your overall life narrative — the story you tell about who you are
- Includes specific personal events (episodic component) and general self-knowledge (semantic component — "I grew up in Chicago," "I'm a teacher")
- **Constructive** in nature — you actively rebuild memories each time you recall them, rather than playing back a recording
- This constructive nature makes autobiographical memories susceptible to distortion, false memories, and narrative reshaping
- Shaped by cultural context, personal identity, and current emotional state
- The **reminiscence bump**: People tend to have more autobiographical memories from ages 15–25 than from other periods, possibly because this is a time of many novel, identity-forming experiences

## Key Brain Regions and Their Memory Roles

| Brain Region | Primary Memory Role |
|---|---|
| **Hippocampus** | Formation and retrieval of new explicit memories; spatial memory; binding features of experiences together |
| **Amygdala** | Emotional memory; fear conditioning; modulating consolidation of emotionally significant memories |
| **Prefrontal Cortex** | Working memory; prospective memory; strategic retrieval; decision-making with stored knowledge |
| **Basal Ganglia** | Procedural memory; habit learning; reward-based learning |
| **Cerebellum** | Motor skill learning; timing; procedural memory |
| **Anterior Temporal Lobes** | Semantic memory; conceptual knowledge |
| **Broca's Area** | Language production; verbally encoded knowledge |
| **Wernicke's Area** | Language comprehension; verbal memory |
| **Neocortex (broadly)** | Long-term storage of consolidated memories across modalities |
| **Entorhinal Cortex** | Gateway between hippocampus and neocortex; grid cells for spatial navigation |
