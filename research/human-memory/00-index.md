# Memory, Knowledge, and Computation: A Complete Reference

## About This Collection

This collection of documents captures a comprehensive exploration of human memory, learning, knowledge representation, and the deep parallels between cognitive science and computer science. It spans neuroscience, cognitive psychology, education theory, data structures, and algorithms.

---

## Documents

### 1. [Types of Memory](./01-types-of-memory.md)
Covers all types of human memory organized by duration (sensory, short-term, long-term) and content (episodic, semantic, procedural, emotional, prospective, autobiographical). Includes Baddeley's working memory model, implicit vs. explicit memory, and the brain regions supporting each type.

### 2. [Memory and Learning](./02-memory-and-learning.md)
Explores how memory and learning are intertwined — the encoding-storage-retrieval cycle, levels of processing, consolidation and the role of sleep, the testing effect, and evidence-based learning principles (spaced repetition, interleaving, elaboration, dual coding). Covers memory failures, the forgetting curve, and interference.

### 3. [From Information to Knowledge](./03-information-to-knowledge.md)
Examines how raw information transforms into knowledge through the DIKW hierarchy (Data → Information → Knowledge → Wisdom), schema theory (assimilation and accommodation), chunking and automatization. Catalogs all categories of knowledge: by source (empirical, rational, testimonial, intuitive), accessibility (explicit vs. tacit), structure (declarative, procedural, conditional, metacognitive), and domain/abstraction level.

### 4. [Knowledge Representation in the Brain](./04-knowledge-representation-in-brain.md)
Deep dive into the neuroscience of how knowledge is physically represented — Hebbian learning, LTP/LTD, localized vs. distributed representation, concept cells. Covers five major theories: semantic networks, schema theory, connectionism/PDP, embodied cognition, and predictive coding. Maps different knowledge types to brain systems and discusses reconsolidation, memory replay, pattern separation/completion, and the stability-plasticity dilemma.

### 5. [Data Structures and Cognitive Parallels](./05-data-structures-cognitive-parallels.md)
Maps every major cognitive system to its corresponding computer science data structure — graphs for semantic networks, trees for taxonomies, hash maps for associative memory, stacks/buffers for working memory, FSMs for procedural memory, matrices/tensors for distributed representation, generative models for predictive coding, cache hierarchies for consolidation, and garbage collection for forgetting.

### 6. [Algorithms: Complete Reference](./06-algorithms-complete-reference.md)
Comprehensive catalog of every algorithm that implements or operates on the data structures from Document 5. Covers graph algorithms (BFS, DFS, Dijkstra, A*, PageRank, community detection), tree algorithms (BST operations, trie search, Huffman coding), hash algorithms (collision resolution, Bloom filters), neural network training (backpropagation, SGD, Adam, dropout, convolution, LSTM, transformers/self-attention), associative memory (Hopfield networks, SDM), decision tree learning (ID3, CART, random forests, gradient boosting), generative models (VAEs, GANs, diffusion), compression (LZ, arithmetic coding, delta encoding), caching (LRU, LFU, ARC), garbage collection, embedding algorithms (Word2Vec, GloVe), similarity search (cosine similarity, LSH, HNSW), and reinforcement learning (Q-learning, TD learning, policy gradients, PPO, actor-critic).

## Key Themes Across All Documents

1. **Memory is not a single system** — it is a collection of interrelated but distinct systems, each with its own brain substrates, computational properties, and failure modes.

2. **Learning and memory are inseparable** — learning is acquisition, memory is retention, and retrieval is itself a form of learning (the testing effect).

3. **Knowledge is constructed, not recorded** — the brain actively builds, organizes, and continuously reorganizes knowledge, not passively stores it.

4. **Computer science and neuroscience have deeply influenced each other** — neural networks were inspired by the brain; our understanding of the brain has been shaped by computational metaphors.

5. **The brain is fundamentally a prediction machine** — knowledge representations serve the purpose of generating predictions, and learning is driven by prediction errors.

6. **Forgetting is a feature, not a bug** — selective forgetting (analogous to garbage collection) keeps the system efficient and focused on relevant information.
